Business Brain AI
=================

رابط تشغيل النظام:
https://krymlyalmhmdy3-del.github.io/business-brain-ai/

حالة النشر
----------
- النشر يتم تلقائياً من الفرع main عبر GitHub Actions وGitHub Pages.
- آخر عملية بناء ونشر تم التحقق منها: ناجحة.
- الصفحة الرئيسية هي index.html في جذر المستودع.

وظائف النظام الحالية
--------------------
- تسجيل دخول المالك عبر Supabase Auth.
- إدارة المنتجات والمخزون.
- إدارة العملاء.
- تسجيل المبيعات مع خصم المخزون تلقائياً.
- تقارير الإيرادات والربح الإجمالي التقديري.
- العملات المدعومة: OMR وUSD وSAR وYER، مع عرض كل عملة منفصلة دون تحويل تلقائي.

قاعدة البيانات
--------------
- المشروع مرتبط بقاعدة Supabase الحالية.
- الجداول: products وcustomers وsales.
- سياسات Row Level Security تقيد الصفوف بصاحب الحساب.
- لا يُسمح للزوار المجهولين بقراءة أو تعديل بيانات المتجر.
- تسجيل البيع يتم عبر الدالة record_sale؛ وهي تتحقق من ملكية المنتج والعميل وتوفر المخزون، ثم تخصم الكمية وتسجل البيع داخل معاملة واحدة.
- يوجد ملف توثيق للتعديل الأمني الأخير في:
  supabase/migrations/20261123044411_secure_owner_data_and_record_sales.sql

بدء الاستخدام
--------------
1. افتح رابط النظام أعلاه.
2. سجّل الدخول بحساب المالك الذي أُنشئ مسبقاً في Supabase Authentication.
3. أضف منتجاتك وعملاءك، ثم ابدأ تسجيل المبيعات.
4. لا تشارك كلمة المرور أو أي مفتاح سري. المفتاح الموجود في واجهة المتصفح هو Publishable key فقط؛ لا تضع service_role في الموقع.

ملاحظات مهمة
------------
- قاعدة البيانات حالياً لا تحتوي على منتجات أو عملاء أو مبيعات فعلية.
- الربح المعروض هو (إجمالي البيع - تكلفة البضاعة) ولا يشمل المصروفات أو الضرائب أو المرتجعات.
- لا توجد مزامنة لتحويل العملات؛ التقارير تفصل كل عملة.
- النسخة الحالية تطبيق ويب بسيط للمالك، وليست بعد نظام اشتراكات متعدد المتاجر.
