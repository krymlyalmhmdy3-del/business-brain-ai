Business Brain AI - النسخة البسيطة للنشر
1) ارفع index.html و database-migration.sql و README-AR.txt إلى جذر مستودع GitHub.
2) قبل النشر، افتح index.html وابحث عن SUPABASE_URL و SUPABASE_KEY واستبدل القيمتين برابط مشروع Supabase والمفتاح العام Publishable فقط.
3) لا تضع service_role أو أي مفتاح سري.
4) نفّذ database-migration.sql مرة واحدة في Supabase SQL Editor لتفعيل تسجيل البيع وتحديث المخزون بشكل آمن.
5) اربط مستودع GitHub بـ Vercel واجعل Framework Preset = Other و Output Directory = . ثم Deploy.
6) اختبر تسجيل الدخول وإضافة منتج وتسجيل بيع.
يدعم OMR وUSD وSAR وYER، والتقارير تفصل العملات ولا تحولها.
